#   • FFT / STFT / spectrogram   (ALPSS — scipy.fft, scipy.fftpack, scipy.signal)
#   • Signal smoothing / peak detection  (scipy.signal.savgol_filter, find_peaks)
#   • Interpolation              (scipy.interpolate.interp1d)
#   • Non-linear optimisation    (scipy.optimize.curve_fit, fsolve)
#   • Special functions          (scipy.special.gamma — SPADE models)
#   • N-D image filtering        (scipy.ndimage.uniform_filter1d)
#
# ShortTimeFFT (scipy.signal.ShortTimeFFT) was introduced in scipy 1.9.0.
# ALPSS falls back to the legacy STFT for scipy < 1.9.0, but 1.9+ is
# recommended for full feature access.
