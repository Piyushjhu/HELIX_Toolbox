# CSV File Formats and Column Headers

This document describes all CSV output files generated by ALPSS and their column headers.

## ALPSS Output Files

### 1. `--velocity.csv`
**Description**: Raw velocity data (unsmoothed)
**Columns**:
- `Time_s` - Time in seconds
- `Velocity_m_s` - Free surface velocity in meters per second

### 2. `--velocity--smooth.csv`
**Description**: Smoothed velocity data
**Columns**:
- `Time_s` - Time in seconds
- `Velocity_Smooth_m_s` - Smoothed free surface velocity in meters per second

### 3. `--vel-smooth-with-uncert.csv` ⭐ (Main file for SPADE)
**Description**: Smoothed velocity with uncertainty analysis
**Columns**:
- `Time_s` - Time in seconds
- `Velocity_Smooth_m_s` - Smoothed free surface velocity in meters per second
- `Velocity_Uncertainty_m_s` - Velocity uncertainty calculated using instantaneous noise analysis (doi.org/10.1063/12.0000870)
- `Velocity_Plus_Uncertainty_m_s` - Upper bound: Velocity + Uncertainty

### 4. `--vel--uncert.csv`
**Description**: Velocity uncertainty data only
**Columns**:
- `Time_s` - Time in seconds
- `Velocity_Uncertainty_m_s` - Velocity uncertainty in meters per second

### 5. `--voltage.csv`
**Description**: Filtered voltage signal (complex IQ components)
**Columns**:
- `Time_s` - Time in seconds
- `Voltage_Real_V` - Real component of filtered voltage (In-phase) in Volts
- `Voltage_Imag_V` - Imaginary component of filtered voltage (Quadrature) in Volts

### 6. `--noise--frac.csv`
**Description**: Instantaneous noise fraction
**Columns**:
- `Time_s` - Time in seconds
- `Noise_Fraction` - Normalized instantaneous noise (dimensionless)

### 7. `--inputs.csv`
**Description**: Analysis input parameters (already has headers via pandas)
**Format**: Pandas DataFrame with parameter names and values

### 8. `--results.csv`
**Description**: Analysis results summary (already has headers via pandas)
**Format**: Pandas DataFrame with result names and values

## SPADE Output Files

### 1. `spall_summary.csv`
**Description**: Spall analysis summary for all shots (already has headers via pandas)
**Format**: Pandas DataFrame with columns including:
- Filename
- Spall Strength (GPa)
- Strain Rate (1/s)
- Peak Velocity (m/s)
- And other analysis metrics

## Uncertainty Calculation Method

The velocity uncertainty (`Velocity_Uncertainty_m_s`) is calculated using:

1. **Noise Estimation**: Fit sinusoid to early signal, calculate residuals
2. **Signal Envelope**: Extract instantaneous amplitude via envelope detection
3. **Noise Fraction**: `inst_noise = std(noise) / (inst_amp / 2)`
4. **Characteristic Time**: FWHM of Gaussian smoothing window (τ)
5. **Frequency Uncertainty**: `freq_uncert = inst_noise × (1/π) × √(6 / (fs × τ³))`
6. **Velocity Uncertainty**: `vel_uncert = freq_uncert × (λ/2)`

**Reference**: [doi.org/10.1063/12.0000870](https://doi.org/10.1063/12.0000870)

## Notes

- All time values are in seconds
- All velocity values are in meters per second (m/s)
- All voltage values are in Volts (V)
- Headers use underscores for compatibility with various CSV readers
- Scientific notation is used for numerical data (e.g., `1.234567890123456789e-06`)
